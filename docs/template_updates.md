# Template updates

A project created from a template has its own history. Template fixes are not
propagated automatically. To adopt them, compare the affected files, adapt changes
to the project's contracts, run its tests and preserve its configuration and data.
Do not overwrite project folders with a full copy of a newer template.

If several projects need frequent updates to the same component or theme, consider
a versioned shared package. The template then provides startup and organisation,
while the package contains the pieces that should evolve together.
